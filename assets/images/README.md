# 📸 Product Images

Place your jersey photos here. Name them exactly as shown below.

## Naming Convention
`[team-slug]-[kit-type]-[view].jpg`

### Examples:
```
real-madrid-home-front.jpg
real-madrid-home-back.jpg
real-madrid-away-front.jpg
lakers-home-front.jpg
chiefs-home-front.jpg
psg-home-front.jpg
```

## Required Views Per Jersey
- `front.jpg` — Main product shot
- `back.jpg` — Back view
- `detail.jpg` — Close-up of badge/logo
- `badge.jpg` — Badge close-up

## Recommended Photo Tips
- Shoot on a plain WHITE or DARK background
- Natural light is best
- Hang the jersey or lay flat — not crumpled
- 1:1 square ratio (1000x1000px minimum)
- JPG format, under 500KB each

## Current Placeholder
Until you add real photos, the website shows emoji placeholders.
Once you add photos, update product.html to reference them:

```js
// In product.html, replace the emoji with:
<img src="../assets/images/real-madrid-home-front.jpg" alt="Real Madrid Home Jersey">
```
